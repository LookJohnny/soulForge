# 咕咕嘎嘎企鹅面部机构复现方案

目标：把论文《Facially expressive humanoid robotic face》里的成人仿真人脸机构，改造成适合“咕咕嘎嘎企鹅”这类动漫/潮玩毛绒角色的第一版可动样机。

## 1. 结论

不要照搬论文里的 Eva 成人硅胶脸。

Eva 的核心结构是：25 个 MG90S 舵机、EcoFlex 00-30 硅胶面罩、Bowden 钢丝拉线、眼球/眼睑/下颌/颈部机构。它适合做人形表情机器人研究，不适合第一版消费级动漫企鹅毛绒样机。

咕咕嘎嘎企鹅应该采用：

- 硬质/半硬质脸部骨架
- 毛绒外壳覆盖
- 局部可动眼睑、嘴巴、头部、身体摇摆
- 腮红灯效和振动反馈
- SoulForge 的 VOCALIZED 模式输出“咕 / 嘎 / 咕咕 / 嘎嘎”

第一版目标不是“逼真人脸”，而是让用户在 20 秒内相信：它看见我、记得我、会用身体和声音回应我。

## 2. 从 Eva 到企鹅的改造原则

| Eva 论文方案 | 咕咕嘎嘎企鹅改造 |
|---|---|
| 成人仿真人脸 | 动漫毛绒企鹅角色 |
| 25 个舵机 | 6-8 个执行器 |
| 全脸 EcoFlex 硅胶面罩 | 毛绒外壳 + 局部 TPU/硅胶软件 |
| FACS 人脸 Action Unit | Anime Expression Unit 动漫表情单元 |
| Stewart 颈部平台 | 简化头部点头/转头 + 身体 waddle |
| Raspberry Pi + 双 Servo Hat | ESP32-S3 + PCA9685 舵机板；如需视觉再加树莓派/手机端 |
| 真人喜怒哀惧惊厌 | 开心、害羞、困、惊讶、生气、撒娇、安抚 |

## 3. 咕咕嘎嘎企鹅表情动作单元

用 AEU 代替 FACS。第一版只需要 8 个动作单元：

| 编号 | 名称 | 机构 | 用途 |
|---|---|---|---|
| AEU-01 | 眨眼/半闭眼 | 左右眼睑共用 1-2 个微型舵机 | 困、害羞、撒娇 |
| AEU-02 | 眼睛发光/变色 | OLED/LED matrix 或 RGB 眼灯 | 开心、惊讶、情绪反馈 |
| AEU-03 | 嘴巴开合 | 1 个舵机拉动嘴部软片 | 咕咕嘎嘎发声时口型同步 |
| AEU-04 | 腮红 | 两侧 RGB LED + 半透明 TPU/硅胶片 | 害羞、开心 |
| AEU-05 | 头部点头 | 1 个舵机或双连杆 | 认同、回应、撒娇 |
| AEU-06 | 头部歪斜 | 1 个舵机或柔性万向结构 | 好奇、困惑 |
| AEU-07 | 身体 waddle | 底部 1 个舵机左右摆 | 企鹅物种特征 |
| AEU-08 | 振动/心跳 | LRA/偏心振动马达 | 被摸、开心、安抚 |

第一版建议优先实现：AEU-01、03、04、05、07、08。

## 4. 推荐结构

### 4.1 外观层

- 黑白企鹅毛绒外壳
- 黄色布料/毛绒喙
- 黄色脚掌
- 可拆卸背部拉链，方便维护内部机构
- 脸部区域用短毛绒或热转印面片，避免硅胶脸出油、沾灰、显脏

### 4.2 面部骨架

- 材料：SLA 树脂、尼龙 3D 打印、ABS 或 PC-ABS
- 作用：承载眼睛、嘴巴、舵机、LED 和固定点
- 形态：一块轻量脸部支架，不做完整人类头骨

### 4.3 眼睛

两种路线：

路线 A：最快打样  
使用固定印刷动漫眼 + 机械眼睑遮挡。优点是外观最像毛绒玩具；缺点是表情变化少。

路线 B：更适合 AI Demo  
使用小 OLED / LCD / LED matrix 显示动态动漫眼。优点是表情丰富，能做星星眼、困眼、眨眼；缺点是更像电子产品，需要调显示质感。

推荐第一版：路线 B，用屏幕眼睛做 Demo，后续量产再评估是否改成印刷眼 + 机械眼睑。

### 4.4 嘴巴

不要复现 Eva 的大面积硅胶下颌。咕咕嘎嘎企鹅只需要一个可开合嘴部模块：

- 外层：黑/粉色 TPU 或薄硅胶嘴片
- 内层：3D 打印小摇臂
- 驱动：1 个 9g 微型舵机
- 控制：根据 TTS 音量或拟声词节奏开合

嘴巴开合角度建议 8-15 度即可，避免毛绒脸变形。

### 4.5 头部与身体

企鹅角色最重要的是 waddle，不是复杂颈部。

推荐结构：

- 头部轻微 nod：1 个舵机
- 身体左右 waddle：底部 1 个舵机 + 摆杆
- 可选头部 tilt：第二版再加

不要第一版做 Eva 的 Stewart 颈部平台。它复杂、重、吵，而且对毛绒企鹅不必要。

## 6. 机械复现步骤

### Step 0：确定目标 Demo

只做一个 20 秒场景：

用户靠近或触摸头顶，企鹅睁眼、脸红、身体左右摇、发出“咕咕！嘎嘎”，然后根据记忆说出内部 thought 对应的动作。

第一版不要同时追求视觉识别、复杂对话和全脸表情。

### Step 1：建立尺寸

建议样机高度：25-30 cm。  
脸部可动区域：宽 80-100 mm，高 60-80 mm。  
内部机构最大厚度：控制在 35-50 mm 内，避免撑坏毛绒外形。

### Step 2：拆分外壳

把企鹅分成 4 层：

1. 毛绒外皮
2. 脸部面片
3. 3D 打印机构骨架
4. 控制板与电源仓

背部保留拉链/魔术贴开口。

### Step 3：做眼睛模块

先不要上复杂眼球转动。

第一版做法：

- 两块 OLED/LCD 固定在脸部骨架上
- 显示动态图案：圆眼、眯眼、星星眼、困眼
- 如果要机械感，再加一个薄 TPU 眼睑片由舵机遮挡

验收标准：

- 眨眼不卡毛绒
- 屏幕亮度隔着面料仍清晰
- 眼睛不能歪，两个眼中心对齐

### Step 4：做嘴巴模块

做一个独立嘴巴小盒：

- 嘴巴外观用 TPU/硅胶薄片
- 内部舵机拉动下唇或嘴内红色软片
- 开合幅度小，不要撑动整张脸

验收标准：

- “咕咕嘎嘎”播放时嘴巴能同步开合
- 连续运行 10 分钟不卡死
- 舵机噪声不盖过声音

### Step 5：做腮红模块

- 左右各一颗 RGB LED
- 外侧覆盖半透明 TPU/硅胶薄片或浅粉布料
- 害羞时亮粉色，开心时暖黄，难过时低亮蓝白

验收标准：

- 不刺眼
- 不透出明显灯珠形状
- 面料不会发热

### Step 6：做头部点头

第一版只做一个 nod：

- 脸部骨架固定在一个小铰链上
- 下方舵机通过连杆让头部前后点动
- 角度 5-12 度即可

验收标准：

- 点头能看出来
- 毛绒帽子不会拉扯机构
- 回中准确

### Step 7：做企鹅 waddle

这是角色灵魂动作。

推荐结构：

- 底部固定一个横向摆杆
- 舵机左右摆动 8-15 度
- 整个身体轻微左右摇
- 脚掌可作为视觉支点

验收标准：

- 开心时能左右摇
- 不会翻倒
- 摇动时内部线缆不缠绕

### Step 8：电子接线

基础接线：

- ESP32-S3 通过 I2C 接 PCA9685
- PCA9685 接所有舵机信号线
- 舵机单独使用 5V 3A 电源
- ESP32 与舵机电源共地
- OLED/LCD 走 I2C/SPI
- RGB LED 走单线数据
- 触摸传感器接 GPIO
- 喇叭走 I2S 功放

注意：

- 不要用 ESP32 5V/3.3V 直接给舵机供电
- 所有舵机动作先限幅
- 线缆要留活动余量

### Step 9：单机动作测试

先不接 SoulForge，只跑固定动作：

1. 眨眼 10 次
2. 嘴巴开合 20 次
3. 腮红亮灭 20 次
4. 点头 10 次
5. waddle 20 次
6. 全动作组合 5 分钟

记录：

- 是否卡住
- 是否过热
- 是否舵机噪声明显
- 电流峰值
- 毛绒是否干涉

### Step 10：接入 SoulForge

SoulForge 现有硬件输出字段可直接映射：

```json
{
  "led": {"expression": "happy", "color": [255, 210, 90], "brightness": 0.85},
  "motor": {"action": "waddle", "speed": 0.55, "intensity": 0.62},
  "vibration": {"pattern": "double", "intensity": 0.45, "duration_ms": 400}
}
```

企鹅角色设置：

```json
{
  "archetype": "ANIMAL",
  "species": "企鹅",
  "languageMode": "VOCALIZED",
  "vocalizationPalette": ["咕", "嘎", "咕咕", "嘎嘎", "咕嘎", "嘎——"]
}
```

映射建议：

| SoulForge action | 企鹅动作 |
|---|---|
| waddle | 身体左右摇 |
| nod | 头部点头 |
| tilt_left / tilt_right | 害羞歪头 |
| bounce | 小幅上下抖动 |
| happy LED | 腮红暖黄/粉色 |
| shy LED | 腮红粉色 + 半闭眼 |
| calm LED | 眼睛柔和 + 低亮 |

### Step 11：做 6 个固定表情 preset

| 表情 | 眼睛 | 嘴巴 | 腮红 | 头部 | 身体 |
|---|---|---|---|---|---|
| neutral | 普通圆眼 | 闭合 | 低亮 | 中位 | 静止 |
| happy | 弯眼/亮眼 | 小开合 | 暖黄 | 点头 | waddle |
| shy | 半闭眼 | 小开 | 粉色 | 歪头 | 轻摇 |
| surprised | 大眼 | 大开 | 白/黄闪 | 后仰 | 停顿 |
| sleepy | 半闭眼 | 闭合 | 低亮 | 下垂 | 静止 |
| upset | 斜眼/低亮 | 闭合 | 冷色 | 轻摇头 | 短振动 |

### Step 12：整机验收

最低验收标准：

- 20 秒 Demo 可连续演示 10 次
- 不拆外壳即可看出表情变化
- 舵机噪声不压过语音
- 连续运行 30 分钟无明显过热
- 触摸响应 < 500 ms
- SoulForge 发出 waddle 时身体确实左右摇
- VOCALIZED 模式下 dialogue 只出现咕/嘎类拟声词

## 7. 关键风险

1. 毛绒干涉机构：所有动作要留足空间，不要让布料绷住。
2. 舵机噪声：优先选低噪数字舵机，动作速度不要太快。
3. 嘴巴开合太贪心：动漫嘴只需要小幅变化，过大会显廉价。
4. 眼睛屏幕质感：屏幕眼容易电子感太强，要加柔光罩或选择高质量显示。
5. 电源不稳：舵机必须独立供电，共地。
6. IP 风险：商业化时不要直接复制图中角色，做原创企鹅风格角色。

## 8. 第一阶段交付物

第 1 周：CAD 草图、脸部骨架、眼睛/嘴巴模块方案。  
第 2 周：3D 打印骨架、眼睛屏幕和嘴巴舵机台架。  
第 3 周：头部 nod、身体 waddle、腮红和振动模块。  
第 4 周：装进毛绒外壳，接 SoulForge，拍 20 秒融资 Demo。  

第一个 Demo 不追求完美外观，只追求“角色活了”的瞬间。

## 9. 第二阶段：参考 Smile Like You Mean It 做学习驱动表情

论文《Smile Like You Mean It: Driving Animatronic Robotic Face with Learned Models》不是新的机械结构论文，而是 Eva 2.0 的控制方法升级。它的关键思想是：

- 不再手工为每个表情写舵机角度
- 让机器人做 motor babbling，也就是随机探索舵机动作
- 用摄像头拍下“每组舵机角度对应出来的脸”
- 训练一个模型学习：目标表情画面 -> 舵机控制指令
- 论文把问题拆成 generative model 和 inverse model，不依赖精确运动学模型、相机标定或预定义表情集

对咕咕嘎嘎企鹅来说，不建议第一版就上这个模型。原因是：

1. 第一版机械结构还不稳定，先训练模型会把机械误差也学进去。
2. 企鹅不是仿真人脸，不需要模仿真人面部 landmark。
3. 早期融资 Demo 更需要稳定、可控、可重复，而不是高自由度学习控制。

但第二阶段非常值得做。推荐改造成“动漫表情学习”，而不是“人脸模仿”。

### 9.1 企鹅版本的数据采集

固定一台摄像头对准企鹅正脸，自动运行所有执行器组合：

- 眼睛屏幕状态
- 眼睑角度
- 嘴巴开合角度
- 头部 pitch / tilt
- 身体 waddle 幅度
- 腮红颜色和亮度

每一帧记录：

```json
{
  "servo": {
    "eyelid": 42,
    "mouth": 18,
    "head_pitch": 88,
    "body_waddle": 104
  },
  "led": {
    "blush": [255, 120, 160],
    "brightness": 0.55
  },
  "eyes": "shy_half_closed",
  "image_path": "dataset/frame_000123.jpg"
}
```

先采 2000-5000 帧即可，不需要一开始做大模型。

### 9.2 企鹅版本的目标表情

目标不再是真人表情 landmark，而是动漫表情标签 + 少量视觉目标：

| 目标 | 表情描述 |
|---|---|
| happy | 亮眼、嘴巴开、腮红暖、身体 waddle |
| shy | 半闭眼、粉色腮红、轻微歪头 |
| sleepy | 眼睑下垂、嘴巴闭合、头低 |
| surprised | 大眼、嘴巴大开、头后仰 |
| upset | 眼睛低亮、嘴巴闭合、短振动 |
| comfort | 柔光、慢点头、低幅度摇晃 |

### 9.3 最小可行模型

不要一开始训练复杂 video-to-video 模型。第一版学习控制可以非常简单：

输入：

```json
{
  "emotion": "shy",
  "p": 0.35,
  "a": 0.25,
  "d": -0.55
}
```

输出：

```json
{
  "eyelid": 55,
  "mouth": 12,
  "head_pitch": 82,
  "body_waddle": 96,
  "blush_brightness": 0.7
}
```

模型选择：

- 第一版：表情 preset + 插值
- 第二版：Random Forest / MLP 回归
- 第三版：摄像头 self-image -> inverse model

### 9.4 什么时候上学习模型

必须先满足以下条件：

- 机械结构连续运行 30 分钟稳定
- 每个舵机都有安全限位
- 6 个基础表情 preset 已经能稳定播放
- 摄像头固定，光照稳定
- 每次回中误差可接受

如果这些没完成，先不要训练模型。

### 9.5 SoulForge 集成方式

SoulForge 继续输出 PAD 和动作意图：

```json
{
  "emotion": "shy",
  "pad": {"p": 0.35, "a": 0.25, "d": -0.55},
  "motor": {"action": "waddle", "speed": 0.3, "intensity": 0.4},
  "voice": {"tone": "soft"}
}
```

企鹅表情控制器负责把它转换为具体硬件指令：

```text
SoulForge PAD / stance
        ↓
Penguin Expression Controller
        ↓
preset / interpolation / learned inverse model
        ↓
servo + LED + eyes + vibration
```

这样不会让大模型直接控制舵机，安全性和可调试性更高。
