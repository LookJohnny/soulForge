# SoulForge — 一个灵魂，多个身体

> **把有记忆、有情绪、有关系的 AI 人格，注入任何载体：毛绒玩具、桌面虚拟形象、耳机、机器人。**
> 用户和"她"的每一次对话都会改变她——而不是每次都从零开始的问答机器人。

*本文面向投资人。工程文档见 [`docs/DEVELOPER.md`](docs/DEVELOPER.md)，仓库内每一项能力都有可运行的测试。*

---

## 1. 我们在解决什么

AI 陪伴的市场已经被验证（Character.AI、Grok Companion、Replika 及国内的大量"AI 女友"应用），但今天的产品有三个结构性缺陷：

| 缺陷 | 后果 |
|---|---|
| **没有真正的记忆和关系** | 用户聊得越久越失望：她记不住上周的事，关系永远停在第一天 |
| **被锁死在一个屏幕里** | 陪伴发生在聊天框，而不是用户生活的物理空间 |
| **每个载体各做一套** | 玩具厂做玩具的 AI，App 做 App 的 AI，人格无法跨设备延续 |

SoulForge 的回答是**"一个大脑，多个身体"**：人格、记忆、情绪、关系进度都在服务端的"灵魂引擎"里；毛绒玩具、桌面 3D 形象、手机、耳机只是她的不同身体。换一个身体，她还是她，记得你。

## 2. 产品现状（仓库内可运行、可验证）

### 灵魂引擎（Python，`packages/ai-core`）
- **五轴关系模型**：好感 / 信任 / 亲密 / 自在 / 尊重 + 精力，8 个关系阶段（陌生 → 灵魂伴侣），阶段升级需要同时满足多个条件和**关键事件**（第一次敞开心扉、告白…），不是一根好感条
- **"应用是游戏主持人"**：LLM 只能*建议*关系变化，引擎按启发式基线夹钳——防止模型自嗨，也让节奏可设计、可运营
- **连续情绪（PAD 三维）+ 情绪因果**：她知道自己"为什么"开心，会随时间平复，长时间不见会想你
- **视觉小说式事件**：28 个里程碑/随机/恋爱/时段事件，选择会真的改变关系并进入后续对话
- **五层记忆 + 语义检索**：本地向量模型（pgvector），带敏感度分级与使用审计——儿童场景可控
- **"活着"层**：不说话时她会无聊、困倦、自言自语；不是等待输入的工具
- 陪伴 / 恋爱两种模式一键切换，适配不同年龄与市场

### 身体（一套大脑，多种载体）
| 身体 | 状态 |
|---|---|
| **毛绒玩具（小智 ESP32）** | 语音全链路打通：VAD → 流式 ASR → LLM → 声优级 TTS → 逐帧 Opus，支持打断；已在真实硬件上运行 |
| **桌面 3D 虚拟形象（浏览器 + macOS 桌面伴侣）** | 完整应用：VRM 形象、动捕 idle、口型、情绪表情、关系 HUD、事件卡、记忆图；Tauri 桌面壳带**透明置顶悬浮伴侣** |
| **通用人形模型** | 不限 VRM：Mixamo / Sketchfab / Unity Humanoid 模型拖进来即可用（合成人形骨架，复用全部动画与表情） |
| **机器人 / 舵机脸板** | Protocol 0.2 身体协议 + 安全钳制（watchdog / 故障锁存 / 安全姿态）；PAD 驱动的机械表情引擎 |
| **Unity 客户端** | 协议客户端可编译；卡通渲染管线在路线图上 |

### 一个可演示的"生活"
`engine/` 是角色的**行为规划引擎**：按日程/小时/分钟三层规划一天，用户打断时四级重规划（微回应 → 暂停恢复 → 重写小时 → 重写全天）。融资样片（`outputs/webgl/dinner_final_video.mp4`）就是引擎实时时间线驱动渲染出来的，不是手 K 动画。

## 3. 为什么是我们能做

- **产业侧入口**：团队来自毛绒玩具制造与外贸一线（义乌），有现成工厂、供应链与 B 端客户——第一个身体不是 PPT，是能量产的玩具
- **工程密度**：135 次提交、~920 项自动化测试（引擎 / 网关 / 规划器三套）+ 浏览器端到端冒烟；每个模块都有可重复验证
- **不绑死任何模型厂商**：6 家 LLM、3 家 TTS 可切换，本地向量记忆，国内外部署都能跑
- **开源生态判断力**：我们系统性评估过同赛道开源项目（如 aikeya），只移植真正有效的设计，并修掉了它们没实现或有错的部分

## 4. 商业路径

1. **B2B2C：玩具厂/IP 方的"灵魂即服务"** —— 工厂出身体，我们出灵魂与运营后台（设计师面板、声音克隆、记忆审计）；按激活设备与对话量计费
2. **B2C：桌面 / 手机陪伴 App** —— 同一个角色跨设备延续，订阅制；恋爱模式与事件内容是持续付费点
3. **IP 授权**：为动漫/游戏 IP 提供"会记得你的角色"，从周边玩具到桌面形象一体交付

## 5. 路线图

| 阶段 | 目标 |
|---|---|
| 近期 | 语音输入体验打磨（桌面端原生麦克风已就绪）；MMD 模型支持；Unity URP 卡通渲染身体（对标国内二次元游戏的画面标准） |
| 中期 | 玩具量产版固件与运营后台商用化；App 端上线；多角色/多用户家庭场景 |
| 长期 | 具身机器人身体（现有安全协议与机械表情引擎为基础）；跨身体的人格迁移标准化 |

## 6. 看看它跑起来

```bash
git clone https://github.com/LookJohnny/soulForge.git && cd soulForge
uv sync --all-packages --dev && pnpm install
docker compose up -d postgres redis
./scripts/live-up.sh          # 灵魂引擎 + 网关 + 规划引擎 + 桌面形象
open http://127.0.0.1:8899/live
```
