# 60 秒演示：一个灵魂，两个身体

目标：让投资人在一分钟内相信一件事——**同一个角色在毛绒玩具和桌面形象之间是连续的**，她记得你、关系在变化。全部镜头都用现有系统实拍，不做后期动画。

## 拍摄准备（约半天）

- 起服务：`./scripts/live-up.sh`；桌面端开 `SoulForge Live.app`（模型选 `AvatarSample_B` 或你自己的 VRM）
- 小智玩具（棉花糖/兔子外壳）连同一个 gateway；`devices` 表里玩具和 `web_vrm-live` 指向**同一个 end_user + 同一个角色**（这样记忆和关系共享）
- 提前聊 2–3 天，把关系推到"朋友"、让她记住一件具体的事（例：你叫小乔、喜欢抹茶拿铁、上周去海边看了日落）
- 录屏：桌面用 QuickTime 录 `.app` 窗口；玩具用手机竖拍，桌面放一个显示 HUD 的 iPad/显示器在画面里更好
- 字幕双语（中文主，英文小字），配轻音乐，不要旁白——让她自己说话

## 分镜

| 时间 | 画面 | 声音 / 字幕 | 想传达的点 |
|---|---|---|---|
| 0–5s | 黑场，一行字："她记得你。不管你在哪里遇见她。" | 音乐起 | 命题 |
| 5–15s | **玩具**：手拿起兔子，说"我回来啦"。玩具回答，主动提起上周的事（"海边的日落好看吗？"） | 玩具真实语音 + 字幕 | 记忆是真的（主动触发，不是复读） |
| 15–25s | 切**桌面**：`SoulForge Live` 窗口，同一角色名；打字"你还记得我喜欢喝什么吗"→ 她答"抹茶拿铁"，口型同步；右侧关系 HUD 好感条 +N 跳动 | 桌面 TTS | 换身体，记忆和关系延续 |
| 25–35s | 桌面：⚙ 切到"陪伴模式"再切回，HUD 阶段变化；点 ◎ 记忆图，节点和语义连线出现 | 字幕："五轴关系 · 语义记忆 · 情绪因果" | 不是聊天框，是有内在状态的人 |
| 35–45s | ⌘⇧U 弹出**透明悬浮伴侣**，拖到桌面角落；她在无人说话时打哈欠/自言自语（活着层） | 字幕："她不等你输入" | 存在感 |
| 45–52s | 触发一个事件卡（例：连续 7 天 / 第一次敞开心扉），点一个选项，她的回应念出来，HUD 跳阶段 toast | 字幕："选择会改变关系" | 可运营的内容体系 |
| 52–58s | 分屏：左玩具、右桌面，同时说同一句"晚安" | — | 一个灵魂多个身体 |
| 58–60s | Logo + 一句："SoulForge — 给任何身体注入灵魂" | 音乐收 | 品牌 |

## 台词控制要点

- 玩具那段一定要让她**先说**（利用主动触发 `proactive_trigger`：新会话首句按关系阶段概率触发记忆回调；拍摄前把 `STAGE_TRIGGER_PROB` 对应阶段临时设为 1.0 保证必触发）
- 事件卡：拍摄账号提前把关系轴推到目标事件条件附近（`GET /relationship/{u}/{c}/events/near` 能看到还差什么）
- 万一 LLM 当次回答跑偏，重录该镜头即可；不要拼接不同账号的画面（会露馅：HUD 数字对不上）
