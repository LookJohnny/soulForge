# 60 秒演示：她是谁，比她多聪明重要

目标：让投资人在一分钟内相信一件事——**人格是基础设施**。三个证据链：现场"锻"出一个灵魂（问卷→出生）、她真的记得（100 轮实测）、一个灵魂装进任何身体。全部镜头用现有系统实拍，不做后期动画。

配套材料：交互展示页（Artifact「SoulForge 演示间」，投资人可自己上手玩问卷和衰减剧场）+ GitHub README（投资人版）。视频负责 60 秒抓住人，展示页负责会后深看。

## 拍摄准备（约半天）

- 起服务：`docker compose up -d postgres redis && ./scripts/live-up.sh` → `http://127.0.0.1:8899/live`
- `.env` 确认：`CONVERSATION_LLM_MODEL=deepseek-reasoner`（角色互聊车道）、`TTS_PROVIDER=edge`；**关 VPN 或给 api.deepseek.com 加 DIRECT 规则**（TUN 劫持会拖慢首句）
- 问卷镜头用**无痕窗口**拍：首次进入 /live 即出问卷，现场真实生成一个新角色（不要用已存在的林晚，出生瞬间才有冲击力）；答案提前排练一遍，锁定生成结果的名字/气质色，字幕好提前做
- 小镇镜头：`configs/characters.json` 里 luna/kai/pipo + 新生成角色都在；角色互聊用聊天框 `@新角色 @luna 你们聊聊` 触发（比等 `SocialPolicy` 自动触发可控；自动触发冷却 180 秒）
- 记忆镜头提前 1–2 天铺垫：告诉她你叫小乔、爱喝抹茶拿铁、最讨厌香菜（与 benchmark 同款事实，字幕可以和曲线图对上）
- 玩具（小智 ESP32）连同一 gateway，`devices` 表玩具与 `web_vrm-live` 指向同一 end_user + 同一角色（记忆和关系共享）；主动开口要必触发就把 `STAGE_TRIGGER_PROB` 对应阶段临时设 1.0
- 录屏 QuickTime；玩具手机竖拍。字幕双语（中文主、英文小字），轻音乐，不要旁白——让她自己说话

## 分镜

| 时间 | 画面 | 声音 / 字幕 | 想传达的点 |
|---|---|---|---|
| 0–5s | 黑场两行字："LLM 把聪明变成了水电煤。" → "但没人回答：这个 AI 是谁？" | 音乐起 | 命题：身份层缺失 |
| 5–16s | **灵魂问卷**快速蒙太奇：三四道情境题的点选（"在意的人很久不回消息，你会——"）→ 生成卡浮现：名字、原型印章（如"雨后森林型"）、气质色晕开 | 字幕："23 道心理学情境题，不是选套餐" | 人格是生成的、契合你的 |
| 16–24s | 她在"她的房间"里出现（VRM 加载、灯光起），第一句用**她自己的音色**打招呼，打字机气泡逐字浮现 | 她的真实 TTS | 出生时刻：问卷→音色→身体→性格一次成型 |
| 24–34s | 对话："你还记得我最讨厌什么吗？"→"香菜，你提过好几回。"；随即插一张实测卡：**100 轮衰减曲线**，静态 prompt 一侧闪过红色的"夜航星/小橘灯" | 字幕："100 轮实测：无运行时的 AI 把用户忘成了三个不同的名字" | 记忆是架构，不是 prompt |
| 34–44s | **小镇**：聊天框输入 `@她 @luna 你们聊聊` → 两个角色走近、轮流发言，打字机气泡一来一往；镜头拉远，第三个角色在自己的日程里走动 | 字幕："没人说话时，她们在生活" | 生活运行时（Generative Agents 内核） |
| 44–52s | 一魂多身：终端敲 `Soul.load("her.soul")` 五行代码 → 分屏：左**毛绒玩具**答话、右桌面 VRM 同一角色名同一记忆 | 字幕：".soul — 跨模型、跨身体、跨厂商" | 身份可携带，是文件不是账号 |
| 52–58s | GitHub README 快速滚动（MIT 徽章、benchmark 图、Roadmap），定格在 spec/ 目录 | 字幕："SDK 开源 · 规范公开 · 身体生态开放" | 基建姿态：做标准，不做孤岛 |
| 58–60s | Logo + 一句："SoulForge — 给任何 AI 一个可携带的灵魂" | 音乐收 | 品牌 |

## 台词与状态控制要点

- 问卷生成结果由答案+种子决定：排练时记下答案组合，正式拍同一组合，名字/颜色不会变
- 角色互聊走 deepseek-reasoner 车道，首句比用户对话慢几秒——**先拍角色走近的空镜**，气泡出来再切近景，节奏就顺了
- 互聊有发言权仲裁（floor）：一方说完对方才接，不会抢话；等一轮完整往返再切镜头
- 记忆镜头如当次回答跑偏，重录该镜头；不要拼不同账号画面（HUD 数字对不上会露馅）
- 玩具段落 AirPods/远场拾音未验证，用近讲或安静房间
