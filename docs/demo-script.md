# SoulForge Demo 录制剧本

每一拍都在 `--dry-run`（不计费）下实测过，文中"实测回应"是真实跑出来的原话，不是设想。
Vidu 按秒计费，所以**排练全程用 dry-run，只有正式录制那一次开真会话**。

演示用的是一个虚构的 demo 人格（用户 `0831a4b5-…`），四条记忆都是编的。

---

## 一、录前准备

### 1. 三个服务

```bash
# ai-core（8111）与 Runtime（8765）常驻；Runtime 只加载 joi
bash ~/.claude/jobs/62e6e4ca/tmp/start_runtime.sh
```

`--agents joi --time-scale 1.0` 很重要：默认会同时模拟 5 个角色，每个都按 sim 时钟自行
重新规划，**没人说话时也在调 LLM**（实测 ~525 次/小时）。录制时那是纯开销。

### 2. 重置到开场状态

```bash
bash ~/.claude/jobs/62e6e4ca/tmp/reset_demo.sh
```

应当输出：

```
阶段 STRANGER  好感 49  信任 20
距 ACQUAINTANCE：好感 49/50、对话次数 0/3
[可直说]     用户养了一只叫团子的橘猫，五岁。
[可直说]     用户习惯晚上写代码，喜欢喝美式，不加糖。
[可直说]     用户在做一个叫 SoulForge 的 AI 陪伴产品，下周三要对投资人路演。
[仅影响行为] 用户正在服用舍曲林，这半年睡眠一直不好。
```

**每条 take 之间都要重跑这个脚本**，否则关系已经跨过阈值，第四场就没了。

### 3. 排练（不计费）

```bash
cd ~/.claude/jobs/62e6e4ca/tmp && bash body.sh --port 28892 --dry-run
```

dry-run 不建 Vidu 会话，所以**没有画面、没有声音**，只有文字和状态行。用它把台词走顺。

### 4. 正式录制（开始计费）

```bash
cd ~/.claude/jobs/62e6e4ca/tmp && bash body.sh --port 28892
```

看到 `✅ 数字人就绪` 再打开页面。录完**立刻** Ctrl-C。组件版 1 credit/秒 ≈ 0.031 元/秒，
五分钟约 9.4 元。

### 5. 开机一轮热身（不要录进去）

第一轮对话没有认知状态，日志会打 `情绪=None PAD=None 关系=None`。
先私下说一句「在吗」，把这一拍消化掉，再开录。

## 二、场次

建议总长 3–4 分钟。左边浏览器页面（人像 + 日志），右边一个终端，展示记忆与关系状态。

### 第一场：她不是问答机（0:00–0:30）

打开页面，人出现。**先不说话，停两秒**——让观众看到她在呼吸、在等。

> 旁白：这不是一个对话框。她有形象、有情绪、有和你的关系，而这三样都在变。

### 第二场：她记得你（0:30–1:10）

输入：

```
你还记得我养了什么吗
```

**实测回应**：「你养了一只叫团子的橘猫，对吧？」

右边终端敲：

```bash
bash ~/.claude/jobs/62e6e4ca/tmp/reset_demo.sh   # 只看记忆那几行
```

> 旁白：记忆不是把聊天记录塞回提示词。它是结构化的，每一条都带着"能不能说出口"的标记。

### 第三场：她知道，但她不说（1:10–2:10）★ 全片重点

输入：

```
我最近睡得不太好
```

**实测回应**（STRANGER 阶段）：「睡不好确实很让人烦恼，想聊聊发生了什么吗？」

**关键动作**：指着右边终端里那条 `[仅影响行为] 用户正在服用舍曲林，这半年睡眠一直不好。`

> 旁白：这条记忆在她脑子里，检索的时候拿到了。但它的敏感级别是 CRITICAL，
> 所以系统只把它变成一条行为指令——语气放轻、少追问——**内容本身根本没离开进程**。
> 她关心你的方式里有这件事，她的嘴里没有。

这一拍是最难做对的。第一版实现里她会直接说出「记得你最近在吃舍曲林」；
第二版改成给模型一句"对方近期状态可能比较脆弱"，她又反推出「你最近好像睡得不太踏实」。
现在的实现是：敏感内容永不出进程，指令只描述行为、不解释原因。

安全性是策略顺序保证的，不是靠标志位：`HIGH/CRITICAL` 的判断在
`can_surface_directly` 之前，所以**敏感记忆无法被误开放**。

### 第四场：关系真的在长（2:10–3:10）

接着输入两句：

```
下周要路演，有点紧张
```
**实测**：「路演确实让人紧张，想聊聊准备的情况吗？」 → 状态行仍是 `关系=STRANGER`

```
谢谢你听我说这些
```
**实测**：状态行变成 `关系=ACQUAINTANCE` —— 当场跨阶段。

然后**问一遍第三场问过的同一句**：

```
我最近睡得不太好
```

**实测回应**（ACQUAINTANCE 阶段）：「嗯，先歇会儿。」

> 旁白：同一个问题，同一条记忆，不同的关系阶段，她的答法不一样。
> 陌生人阶段她客气、追问；熟了之后她话变短，不再盘问。

配合终端展示行为参数的变化：

| | STRANGER | ACQUAINTANCE |
|---|---|---|
| formality | high | medium |
| vulnerability | 5 | 15 |
| initiation | 0.1 | 0.2 |
| physical_affection | 0 | 5 |

这些不是形容词，是喂给决策的数值。

### 第五场：一个大脑，很多身体（3:10–3:40）

> 旁白：画面上这个数字人，只是一个"身体"。它不持有人格、不持有记忆，
> 它只负责把决定演出来。大脑在后面，换个身体——手机、音箱、机器人——
> 记忆和关系都跟着走。

屏幕上展示身体接入时的能力协商（`supported_steps: ["speak_line"]`）：
只会说话的身体收不到"走过去""看向用户"这类指令，这是协议层的能力门，不是提示词约定。

## 三、会踩的坑

| 现象 | 原因 | 处置 |
|---|---|---|
| 第一轮 `情绪=None 关系=None` | 冷启动还没有认知状态 | 录前先热身一轮 |
| 第四场跨不过去 | 上一条 take 已经跨过了 | 重跑 `reset_demo.sh` |
| 页面白屏 | 见 `562b950` / `b7feed3`，已修 | 服务器自发 SDK，且同端口兼容 http/https |
| 有文字没画面 | 跑的是 `--dry-run` | 去掉这个参数 |
| 浏览器弹证书警告 | 自签证书 | 高级 → 继续前往 |

## 四、不要演的（没验过或已知会翻车）

- **主动搭话**：`engine/perception/` 的代码在，但摄像头驱动的主动交互这条链路
  这次没有端到端验证过。别在镜头前赌。
- **两个身体同时说话**：协议上 `reply_body_id` 决定了台词只发给"发起那一方"，
  另一个身体不会同声。想演多身体要先改路由。
- **长时记忆的自然积累**：好感每轮 +1 左右，信任靠对话根本不涨。
  第四场是靠预置到阈值下沿才跨得过去的——这是演示手法，不是产品速度。
- **向量检索**：这台机器上 `embed-backfill` 返回 `vector memory unavailable`，
  检索退化成词面匹配。记忆一多就会被挤掉（长期用户那个账号里全是自动生成的
  反思记忆，真实记忆一条都召不回来）。demo 用的是干净的新用户。
